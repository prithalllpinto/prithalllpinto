## Featured projects

### Rail Defender: Cyber-Physical Fault vs Cyberattack Detection
Real-time system that tells hardware faults apart from cyberattacks on railway sensor data. Fuses Isolation Forest (1.5M sensor readings) and XGBoost (126K network records), streams data over MQTT, and shows live status with SHAP explanations on a Flask dashboard.
`Python` `XGBoost` `Isolation Forest` `SHAP` `MQTT` `Flask`
Research paper accepted at IEEE MPCIT 2026.

### Login Anomaly Detection System
End-to-end security monitoring application: PostgreSQL event schema, Spring Boot ingestion API, rule-based detection engine, and React dashboard. Flags repeated failed attempts, logins from new locations, and unusual login hours.
`Spring Boot` `PostgreSQL` `React.js`

### Bharatanatyam Mudra Gesture Detection
Computer vision system for 49 mudra classes (~37K images) using transfer learning. MobileNetV2 with Spatial Attention reached 97.15% accuracy, with Grad-CAM visualisation and a Flask demo app.
`Python` `TensorFlow` `Keras` `OpenCV` `Flask`
